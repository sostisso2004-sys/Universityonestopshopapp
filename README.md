
# Molloy University — One-Stop Shop App

A student-centered mobile app prototype designed to bring everything a Molloy University Lion needs into one place — from academics and campus services to events, wellness, and more.

Built as a proof-of-concept prototype using Figma.

---

## What It Does

The One-Stop Shop App aims to simplify and enhance the student experience by consolidating the most important university touchpoints into a single, intuitive interface. No more jumping between a dozen different apps and websites.

---

## Features

- **Home Dashboard** — Personalized overview with quick access to all key areas
- **Academics** — Course information, schedules, and academic resources
- **Events** — Campus events calendar and announcements
- **Shuttle** — Shuttle schedules
- **Student Services** — Counseling and career appointment booking
- **Fitness Center** — Fitness schedules and facility information
- **Career Center** — Career resources and appointment scheduling
- **Financial Information** — Financial aid and billing overview
- **Work Orders / Maintenance** — Submit and track maintenance requests
- **Spirit Store** — Molloy merchandise and Lions gear catalog
- **Residence Life** — Housing information and resources
- **Library** — Library resources, hours, and book checkouts
- **Notifications** — Campus-wide announcements and alerts
- **Student Profile** — Personalized student account view

---

## Current Status

> **Early Prototype / Proof of Concept**

This is a front-end prototype built in Figma and exported as a React application. All data is currently static and hardcoded for demonstration purposes. The following would need to be implemented by the development team before production use:

- Authentication and single sign-on (SSO) integration with Molloy systems
- Connection to live student data (Banner, LMS, etc.)
- Real-time shuttle tracking API
- Live financial and academic record integration
- Backend infrastructure and database
- Mobile app packaging (iOS / Android)

---

## Tech Stack

This prototype was exported from Figma and uses the following technologies:

- **React** with TypeScript
- **Vite** (build tool)
- **Tailwind CSS** (styling)
- **Radix UI / shadcn** (UI components)
- **React Router** (navigation)
- **Recharts** (data visualization)

---

## Running the Prototype Locally

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open your browser and go to `http://localhost:5173`

## Project Background

This app was conceived, designed, and prototyped by a Molloy University student with the goal of improving the day-to-day experience for the Lions community. The prototype was presented to and approved for further development by Molloy University's CIO, directors, and technology team.
